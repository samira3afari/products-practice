# Products Grid Practice

A responsive product grid built with CSS Grid.

## Technologies
- HTML5
- CSS3 (Grid, Flexbox)

## Features
- Responsive grid with `repeat(auto-fit, minmax(250px, 1fr))`
- No Media Query needed for layout (auto-responsive)
- Featured card with `grid-column: span 2`
- Consistent image sizing with `object-fit: cover`
- Buttons aligned to bottom with `margin-top: auto`
- RTL support

## Responsive Behavior
- Desktop: 3-4 cards per row
- Tablet: 3 cards per row
- Mobile: 1 card per row
